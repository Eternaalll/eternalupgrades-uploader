Privacy Policy

EternalUpgrades Uploader. Last updated: 24 November 2026.

What this app is

EternalUpgrades Uploader is a private tool used only by the owner of the EternalUpgrades YouTube channel. It runs on the owner's own computer and uploads the owner's videos to that channel. It is not offered to the public.

YouTube API Services

The app uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

After the channel owner signs in with Google, the app can access that owner's own YouTube account in order to:

  • read the channel's name and ID, to confirm the right channel is signed in
  • upload videos and set their title, description, tags, thumbnail, publish time and playlist

The app does not access, collect or store data about viewers, commenters or any other person.

How data is stored

The only thing the app stores is a Google sign-in token, saved in a file on the owner's own computer so the owner does not have to sign in each time. The app has no server and no database. It uses no cookies, no analytics and no advertising.

Sharing

No data is sold, shared or sent to anyone. Data only travels between the owner's computer and Google's YouTube API.

Removing access and deleting data

Access can be removed at any time on the Google security settings page: myaccount.google.com/permissions. Deleting the token file from the computer deletes all data the app has stored.
